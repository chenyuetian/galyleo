# Scheduler Options

Every galyleo session runs as a batch job submitted to Slurm. As such, 
you must specify the following key command-line options to request the
compute resources required for the job.

- `-A, --account`: charge the compute resources required by this job to
  the specified account (e.g., `abc123`)
- `-p, --partition`: select the resource partition (or queue) for the
  job (e.g. , `debug`)
- `-c, --cpus`: number of cpus to request for the job
- `-m, --memory`: amount of memory (in GB) required for the job
- `-g, --gpus`: number of GPUs required for the job
- `-t, --time-limit`: set a maximum runtime (in HH:MM:SS) for the job
