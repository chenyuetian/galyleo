# Jupyter Options

galyleo currently supports a limited set of the standard Jupyter 
command-line options.

- `-i, --interface`: select the user interface for the Jupyter notebook
  session; `lab` or `notebook` or  `voila` (default: `lab`)
- `-d, --notebook-dir`: path to the initial working directory for the
  notebook session (default: `$HOME`)
