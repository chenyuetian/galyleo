# Additional Information

Additional information about the galyleo project.

## Web Portal Integration

galyleo is integrated with the Open On-Demand-based [Expanse](https://portal.expanse.sdsc.edu)
and [TSCC](https://portal-tscc.sdsc.edu) user web portals. After logging
into either portal with your ACCESS-CI credentials, you can access this
web-based frontend interface to galyleo from the pinned *Jupyter*
application shown on the main dashboard. You can also find it located
under the the *Interactive App (Work)* tab in the toolbar across the top
of your browser window, where you can select *Jupyter* from its drop-down
menu.
